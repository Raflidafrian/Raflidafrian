### 📌 About DentalCare

**DentalCare** adalah sistem informasi manajemen praktik dokter gigi berbasis web yang dikembangkan untuk membantu proses administrasi dan pelayanan klinik secara digital.

### ✨ Main Features

| Module | Description |
|---|---|
| 👤 Patient Management | Mengelola data pasien |
| 👨‍⚕️ Doctor Management | Mengelola data dokter |
| 📅 Appointment | Booking dan pengelolaan jadwal |
| 🦷 Dental Records | Pengelolaan rekam medis |
| 🧩 Odontogram | Pencatatan kondisi gigi |
| 💊 Medicines | Pengelolaan obat |
| 💊 Prescriptions | Pembuatan resep |
| 💰 Billing | Pengelolaan tagihan |
| 💳 Payment | Pengelolaan pembayaran |
| 🔐 Authentication | Login & role-based access |
| 📊 Dashboard | Dashboard berdasarkan role |
